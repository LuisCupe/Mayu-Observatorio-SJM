## Publicar en GitHub Pages

1. Crea un repositorio nuevo (por ejemplo `mayu-web`) y sube **todo el contenido** de esta carpeta, incluido el archivo oculto `.nojekyll`.
2. En el repositorio: **Settings → Pages → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. En uno o dos minutos queda en `https://<tu-usuario>.github.io/<repositorio>/`.

## Notas

- Todo usa rutas relativas: funciona en Pages y con doble clic en `index.html`.
- Necesita internet para el mapa base (Esri), Leaflet, las tipografías y las fotos y videos de Wikimedia/YouTube del story map.
- El código para regenerar el Centro (`codigo/`) y el generador del story map siguen en sus repositorios `centro-decision-mayu` y `StoryMaps-Mayu`; aquí solo va lo publicable.
- Apoya la gestión preventiva y no reemplaza las alertas oficiales de SENAMHI, INDECI ni el SISMATE. Emergencias: 115 (Defensa Civil) · 116 (Bomberos).
